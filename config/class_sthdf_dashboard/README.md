# Roster 2026-2027

`roster_2026-2027.csv` je mapovanie meno → pridelené ST0XX/PRJ0YY číslo.
Vypĺňa vyučujúci pred/na začiatku semestra a oznámi ho študentom (LMS,
Teams, e-mail).

Prečo je to potrebné: `students/ST0XX/` a `projects/PRJ0YY/` priečinky v
tomto repozitári (`content/docs/sk/class_sthdf_dashboard/.../students/`,
`.../projects/`) sú vygenerované vopred pre celú kapacitu triedy — bez
tohto rosteru študent nevie, ktorý z nich je jeho.

Ako sa výstup dostane do svojho slotu: pozri
[K000119 – Ako si vytvoriť čistý klon triedneho repozitára](https://knifes.systemthinking.sk/sk/knifes/K000119-klon-triedneho-repozitara)
(krok 6, "Publikovanie výstupu do triedneho repozitára").
