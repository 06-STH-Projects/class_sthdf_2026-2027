# Submissions

Sem prichádzajú hotové výstupy študentov formou Pull Requestu — každý
vo vlastnom podpriečinku, pomenovanom podľa dohodnutej konvencie:

- `ST-XXX-MojeMeno/` — individuálna práca
- `PRJ-YYY-NazovProjektu/` — tímový projekt

Postup zverejnenia je popísaný v
[K000119 – Ako si vytvoriť čistý klon triedneho repozitára](../content/docs/sk/knifes/K000119-klon-triedneho-repozitara/index.md)
(krok 6, "Publikovanie výstupu do triedneho repozitára").

Skopíruj celý svoj repozitár do podpriečinka s vlastným menom, commitni
a otvor PR do `main`. Nekopíruj `.git/` — chceme len obsah, s jedným
submission commitom.
